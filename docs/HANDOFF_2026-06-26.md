## 1. TOAI 2.0 — the new front door (built this session)
The system is **meta-labeling** (López de Prado) — an ML model that filters the
primary strategy's signals. Full roadmap: `docs/ROADMAP_TOAI_2.0.md`.

### Cockpit — one screen, one button  (`toai/cockpit.py` + `TOAI.bat`, port 8766)
Drop an export + have bar_data, press **Build TOAI** → the whole pipeline runs and
shows ONE verdict card: **TRUST**, out-of-sample AUC, **edge/trade**, reversion
features ON/OFF, **SHAP** drivers, the **Strategy-vs-TOAI** equity curve, a
**threshold slider + Apply to chart**, and **Activate as live model**. The old
full dashboard stays at `TOAI_Analytics_App.bat` (port 8765).

### ML foundation upgrades (`train.py`, `label.py`, `merge.py`)
- **Triple-barrier labeling** (`toai/label.py` `meta_label`): label each trade by
  which barrier hits first — from MAE/MFE (in **$**, ÷ point value → points) + the
  trade's recorded **Stop/Take**. Falls back to `PnL>0` when barriers absent, so
  old data trains unchanged. `merge.match_trades` now carries
  MAE/MFE/StopLoss/TakeProfit/EntryPrice/Qty into `training_data.csv`.
- **LightGBM** is the estimator (`_make_estimator`; sklearn GradientBoosting
  fallback if lightgbm missing). **SHAP** top features stored in the bundle
  (`shap_top`) → shown in the cockpit. Walk-forward gained an **embargo**
  (CPCV-lite) to purge time leakage.
- **Verified:** on the current MES data (263 trades, no OHLC) this alone lifted
  purged OOS **AUC 0.51 → 0.53**, **TRUST none → weak**, with honest SHAP drivers.
  Tested on a temp copy — the live `model.pkl` was NOT overwritten.

### Also this session
- `build_and_train(include_live=True)` folds **Sim101 + funded live fills** into
  training (`merge.live_training_rows`); checkbox in Control → Actions.
- **Per-variant strategy-mode tag** (`variants.set_mode`/`sync_mode`): tag each
  model Auto/Standard/Mean-Reversion in the variants table; the ACTIVE model's tag
  writes `mode_manual.txt` → drives the HUD.

## 2. Bug fixes that matter (don't regress these)
- **MAE/MFE are in DOLLARS, not points** — see `[[toai-mae-mfe-units]]`. Fixed
  `simulate_sltp`, `sltp_grid`, `exit_efficiency` to convert ÷(point value × qty).
  This was silently making the Simulator and exit-efficiency ~5× wrong on MES.
- **`variants` was never imported in `dashboard.py`** — every `variants.*` call
  raised NameError, swallowed by `except → reg={}`, so the "Active model /
  variants" panel ALWAYS showed "No variants yet". Fixed by adding it to the
  package imports.
- **Threshold sync** — the dashboard writes `<inst>/threshold.txt`; the chart HUDs
  used to read only the ROOT `threshold.txt` (55) and only once per bar. Both
  `TOAIExporterGaugeTick` AND `TOAIGaugeHUD` now read the **per-instrument** file
  first and **re-read every tick** (stat-checked). Needs F5.
- NinjaScript: `MlFilterPassed` `[Browsable(false)]+[XmlIgnore]` (template
  deserialize crash); `ShowModeBadge` toggle (default off) on both HUDs; gauge
  panel dropped +10px.
