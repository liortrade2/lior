## What this session changed

### 1. ML pipeline — calibration, trust, mean-reversion features
- **Probability calibration** (`train.py`): the model is now wrapped in
  `CalibratedClassifierCV` (Platt/sigmoid). Raw scores used to swing 0.1→99.9
  (the misleading "18% that won"); calibrated they sit near the true base rate.
  Brier + ECE reported.
- **TRUST verdict** (`train.py` `_trust`/`_ece`): the bundle now stores
  `trust` / `wf_mean` / `wf_ece` / `brier_*`. Current model verdict = **`none`**
  (walk-forward AUC ≈ 0.51 ≈ random — 263 long-only trades is too little data).
  Shown in the dashboard 🎯 ML edge tab as a coloured badge.
- **Mean-reversion candle-shape features** (`features.py`): `BodyDir_ATR`,
  `ClosePos`, `LowerWick_ATR`, `UpperWick_ATR`, `DipDepth_ATR` — derived from the
  OHLC the exporter already writes. `merge.py` now carries OHLC into
  training_data.
- **Adaptive feature selection** (`train.py` `usable_features`, ≥80% coverage):
  candle-shape features auto-activate once OHLC-rich bar history exists, else the
  model falls back to the base 11. **They are OFF today** because only ~1% of the
  historical training bars have OHLC (it was added to the exporter recently).
  `scorecard.py`, `edge_scan.py`, `expectancy.py` were all updated to use
  `usable_features` (otherwise dropna on the full feature list wiped every row).
